# Bancos de preguntas - Exam Lab

Esta carpeta contiene los bancos de preguntas de cada examen de certificación.

## Estructura de carpetas

Cada certificación debe tener su propia carpeta. El nombre debe coincidir con el identificador utilizado en `catalog.json`.

```text
data/
├── catalog.json
├── case-studies.json
├── README.md
└── exams/
    ├── dp-600/
    │   ├── questions.json
    │   └── case-studies.json
    ├── dp-700/
    │   └── questions.json
    └── az-900/
        └── questions.json
